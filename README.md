### 🚲 Fair'repair — plateforme de réservation de réparation de vélo

PHP 8 · MySQL · MVC sans framework · PDO · Stripe · Leaflet
**[→ Voir le code](https://github.com/roytitli119-design/Fairepair)**

Projet de synthèse de BTS SIO SLAM. Trois rôles — client, réparateur, modérateur — sur

### 🌸 Ma Vie Admin — gestion de finances personnelles

JavaScript · `localStorage` · HTML/CSS · une seule page, sans dépendance

Application 100 % locale et hors-ligne : dépenses et budgets, épargne et compte courant,
heures de travail, impôts, documents, rappels. 8 modules, environ 2 300 lignes, aucune
